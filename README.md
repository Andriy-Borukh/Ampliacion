📊 Gestor y Filtro de Datos CSV

Aplicación desarrollada en Java que permite leer, procesar y mostrar información almacenada en un archivo CSV.

El programa recopila los datos del archivo y permite al usuario consultarlos mediante diferentes opciones de búsqueda y filtrado.

📋 Descripción

La aplicación se encarga de:

📂 Leer los datos de un archivo CSV.
🔄 Procesar y organizar la información obtenida.
📋 Mostrar los datos al usuario.
📊 Consultar la información según diferentes criterios.

El objetivo principal es facilitar la consulta de un conjunto de datos sin necesidad de revisar manualmente todo el contenido del archivo.
